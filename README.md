# Support router for displaced residents

Routes a displaced resident's request to the right regional service, with the documents each one needs.

## Overview

Encodes the region's referral map for internally displaced people: housing, payments, documents and health, with the documents each service asks for.

## Interfaces

Protocol: `other`. Languages: uk, en.
